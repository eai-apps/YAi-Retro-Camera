# Дополнительные модули (Features)
Каталог зарезервирован под модули будущих этапов:
- photobooth/ (фотобудка, вертикальная лента)
- collage/ (коллажи)
- polaroid/ (режим полароида с рамками)
- pose-guide/ (поза-подсказка из галереи)

На Этапе 0 не подключаются для сохранения чистоты и фокуса на сквозном пайплайне видеозаписи и склейки.
