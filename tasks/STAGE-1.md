# Этап 1 — полноценная первая версия YAi Retro Camera

Основание: HANDOFF §2, §6, §7 (MVP), решения §13 и замечания владельца 02.11.2026 после stage-0-3.

Этап 0 проверял технологию. Владелец подтвердил запись/склейку на Xiaomi Mi 8, Android 10; звук не подтверждён: небольшой треск, голос специально не записывался, тихий телевизор не различался. Не считать звук исправным или неисправным без измерения/новой проверки.

Обязательная поставка этой задачи:

- Фото и видео; шесть бесплатных декларативных камер: 8 мм, VHS 80-х, мыльница 90-х, одноразовая, CCD, полароид.
- Реальные многослойные эффекты в превью и файле: собственная тональная LUT, цвет, зерно, виньетка, пыль/царапины/засветки по профилю. Ползунок силы; изменение стиля до экспорта.
- Для камер с ограничением сочетания потоков: явно отмеченный режим совместимости видео с оригинальным превью и эффектом при сохранении, без скрытого снижения качества записи. На поддерживающих два потока камерах используется живой Skia-эффект.
- Лента: просмотр исходника, удалить кусок, переставить, новая съёмка, очистить всё с подтверждением; удалённые куски не участвуют в экспорте. Сохранённая галерея приложения с просмотром/удалением собственных фото и видео, включая stage-0-3; не удалять чужие медиа.
- Full HD по умолчанию; выбор 720p / Full HD / 4K только по возможностям конкретной камеры. Показать фактическое разрешение. Никакого скрытого понижения до 720p. Экспорт исходного формата и 9:16.
- Дата/время, редактируемый штамп, REC; живой звук по умолчанию, отдельные режимы плёночного и без звука. Просмотр/диагностика исходного звука до склейки. Не добавлять треск автоматически.
- Фото: полароид, фотобудка из четырёх кадров, коллаж; импорт фото/видео через системный выбор.
- Два реальных оформления интерфейса: современное и ретро; понятные доступные элементы управления. Своя launcher/adaptive иконка.
- Настройки сохраняются. При открытии — явное предложение продолжить/начать новую съёмку, а не незаметное дописывание.
- Минимум Android 10 (API29) по прямому решению владельца 02.11.2026. Старые Android и их обходы не поддерживать. MediaStore/scoped storage без разрешений READ/WRITE_EXTERNAL_STORAGE; системный импорт выбранных файлов, GPU-эффекты и аппаратный H264/AAC. Качество определяется возможностями конкретной камеры и кодека: Full HD по умолчанию, доступный 4K, максимальное фото; не снижать качество ради старых ОС. Текущая матрица native/UI — API29/35. Xiaomi Mi 8 / Android 10 — основной следующий физический тест.

Бюджет 0, полностью локальная обработка, без водяного знака/искусственных лимитов, без магазина/монетизации/iPhone/ИИ и новых серверов. Код/ресурсы только своего авторства или с совместимой лицензией.

Проверка: TypeScript, содержательные тесты удаления/порядка/настроек/экспорта, компиляция шейдеров, автономный bundle, Android CI, подпись и SHA.
