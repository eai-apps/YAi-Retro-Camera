# YAi Retro Camera

Ретро-камера для Android (позже iPhone): фото и видео в стиле 8 мм, VHS, мыльниц 90-х, полароида и CCD 2000-х.
Главная фишка — пауза и продолжение записи, склейка кусков прямо в приложении.

**Статус:** идёт разработка (Этап 0 — проверка технологии).

Всё о проекте, правила и журнал работ — в [HANDOFF.md](HANDOFF.md).
