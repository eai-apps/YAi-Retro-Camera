# YAi Retro Camera — первая полная версия Android

Фото и видео с шестью ретро-камерами, локальная обработка без оплаты, аккаунта, водяного знака и ограничения длины. Задание владельца: [tasks/STAGE-1.md](tasks/STAGE-1.md). История прототипа и доказательства: [REPORT.md](REPORT.md).

**Статус 02.11.2026:** исходники версии 0.2.0 готовы к Android CI. Локально прошли TypeScript, 39 тестов и компиляция SkSL; native/API 26–35 ещё проверяются. Старый stage-0-3 — только прототип. Владелец подтвердил на Xiaomi Mi 8 / Android 10 запись и склейку, звук и новую версию пока не проверял.

## Возможности

- Фото/видео: 8 мм, VHS 80-х, мыльница 90-х, одноразовая, CCD, полароид. Сила эффекта, дата/свой штамп, REC.
- Full HD по умолчанию; 720p/Full HD/4K по возможностям выбранной камеры, фактическое разрешение в видоискателе. Исходный формат, 9:16, 1:1, 16:9.
- Лента видео: открыть исходник, измерить звук, удалить отдельный кусок, изменить порядок, очистить черновик, склеить. При запуске — явный выбор продолжить или начать заново.
- Фото: отдельный кадр, полароид, фотобудка с четырьмя кадрами и обратным отсчётом, коллаж. Предпросмотр и сохранение JPEG. Импорт фото/видео системным окном.
- «Мои работы»: просмотр, удаление одной или всех сохранённых работ приложения, включая старые тестовые видео. Удаление здесь удаляет файл и из галереи телефона.
- Живой звук по умолчанию; плёночный звук и без звука выбираются отдельно. Искусственный треск не добавляется.
- Современный/ретро-интерфейс, своя иконка, сохранение настроек. Android 8+; ARM64/ARMv7 и x86_64 для проверок.

## Установка обновления

1. На телефоне открыть [Releases](https://github.com/eai-apps/YAi-Retro-Camera/releases). Выбрать последний релиз **YAi Retro Camera 0.2.0** после окончания проверок.
2. **Assets → YAi-Retro-Camera-0.2.0.apk → Скачать → Открыть → Обновить**. Старое приложение не удалять, чтобы сохранить черновики. Подпись тестовая, как у stage-0-3; магазинных ключей нет.
3. Разрешить камеру, для видео со звуком — микрофон. На Android 8–9 при сохранении/просмотре своих работ потребуется разрешение хранилища. На Android 10+ широкий доступ к галерее не запрашивается.
4. **Настройки → Качество → Full HD**, **Звук → Живой**. Если камера не поддерживает выбранное качество, приложение сообщает о переключении.
5. Для удаления старых видео: **Мои работы → Удалить** у ролика или **Удалить все сохранённые работы → подтвердить**. Для новых пустых исходников: **Видео → Очистить всё → Удалить куски**.

## Проверка на Xiaomi Mi 8

Снять фото всеми шестью камерами и сравнить сохранённые файлы с превью. Сделать полароид, фотобудку, коллаж и импорт. В видео записать три куска со словами «один», «два», «три» и хлопками; удалить второй, переставить оставшиеся, сохранить. Открыть через обычную Галерею, проверить порядок, разрешение, голос, эффект и совпадение хлопков. Проверить обе камеры, 720p/Full HD и доступный 4K, удаление черновика и старых сохранённых роликов, восстановление после перезапуска. CI не заменяет эти проверки реального сенсора и микрофона.

## Сборка

Каноническая среда: GitHub Actions Ubuntu 22.04, Node 22, JDK 17, SDK/build-tools 35, NDK 26.1.10909125. `npm ci`, `npm run typecheck`, `npm test -- --runInBand`, `npm run check:shaders`, `npm run check:shader-compile`, `npx expo export --platform android`, `npx expo prebuild --clean --platform android`, `cd android && ./gradlew assembleRelease`.

Workflow также проверяет реальные нативные фото/галерею/удаление/звук и склейку синтетических MP4 на Android API 26/29, затем запускает автономный APK на API 29/35. Тестовые MP4 создаются ffmpeg только в CI; ffmpeg не включён в приложение. Релиз публикуется только после успешных проверок всех задач. Новые камеры — отдельные декларативные файлы `src/cameras`; общие формулы GPU — `effects/warm-film.glsl`, параметры — `effects/parameters.json`, CPU-обработка фото — `PhotoEngine/FxConfig`. Новые ресурсы заносить в [assets/LICENSES.md](assets/LICENSES.md).
