## 2. Что это за проект

**YAi Retro Camera** — мобильное приложение «ретро-камера»: фото и видео в стиле старых камер. Выбираешь «старую камеру»
(8 мм, 16 мм, VHS 80-х, мыльница 90-х, одноразовая, полароид, CCD 2000-х) и снимаешь сразу в её стиле.
Собираем **лучшее из всех конкурентов** в одном приложении.

- **Главная фишка (хук):** пауза / стоп → снова снимать → куски видны на ленте → удалить / переставить → склеить →
  сохранить одним роликом. У конкурентов этого нет (в отзывах прямо просят паузу).
- **Второй хук:** бесплатно — без лимита длины записи, без лимита сохранений, **без водяного знака**.
  Платно — только дополнительные камеры (разовая покупка, без подписок).
- **Бюджет 0 €.** Сначала **Android**, потом iPhone. Магазины: Google Play, RuStore, позже App Store.

**Статус (01.11.2026): задание готово, кода ещё нет.** Antigravity выполняет [tasks/STAGE-0.md](tasks/STAGE-0.md) в указанной там папке TempCode; затем Codex проверяет код и собирает APK.

### Конкуренты и что у них брать

| Приложение | Что взять |
|---|---|
| Rarevision VHS | помехи при встряхивании, фейковый зум, своя дата, анимированные титры, «плохой» ретро-звук |
| 1998 Cam | дата-штамп, пыль, засветки, зерно, фотобудка, режим «плёнки», без водяного знака |
| Dazz | набор моделей камер; видео 8 мм / 16 мм / VHS / DCR / диапроектор; двойная экспозиция; ISO/выдержка; рыбий глаз |
| Vintage Film Camera | эффект «прожига» плёнки, механические звуки, дописывание кусков |
| VHS Cam + 8mm | оверлей REC, дата и титр, выбор: живой звук или винтажный |
| Prequel | шаблоны, много эффектов |

Их слабые места (делаем лучше): подписки и пейволлы, лимиты секунд, нельзя менять силу эффекта, запутанное меню,
нельзя редактировать после съёмки, нет паузы.

## 4. Устройство кода (план — уточнить на Этапе 0)

**Стек (предложение):**
- **React Native + Expo**, development build (не Expo Go — камере нужен нативный код).
- Камера: `react-native-vision-camera` (MIT).
- Эффекты на GPU: `@shopify/react-native-skia` (MIT) — шейдеры, LUT, зерно, наложения.
- Куски видео — в папке приложения; итог — в галерею телефона.
- Сборка APK — **GitHub Actions** (бесплатно; на ПК владельца Android Studio не обязателен).

**Папки (чтобы новое добавлялось легко, без переписывания):**
```
src/cameras/      каждая камера = ОДИН файл-описание (название, фото/видео, LUT, зерно, засветки, рамка,
                  формат даты, звук, free/paid). Новая камера = новый файл, движок не трогать.
src/engine/       движок эффектов (шейдеры), общий для всех камер
src/recorder/     запись кусков, пауза, лента кусков, склейка, экспорт
src/features/     отдельные модули: фотобудка, коллаж, полароид, поза-подсказка… (подключаются по одному)
assets/luts/  assets/textures/  assets/sounds/   ресурсы — только с подходящей лицензией,
                  источник каждого файла → assets/LICENSES.md
tasks/            задания для помощников (STAGE-0.md и т.д.)
REPORT.md         отчёты помощников (новые сверху)
.github/workflows/android.yml   сборка APK
```

**⚠️ Главный технический риск:** запись **видео с эффектом** (а не только превью) + склейка кусков без рассинхрона звука.
Проверяется **первым** (Этап 0). Если стек не тянет — вариант Б: снимать чистые куски, эффект накладывать при экспорте
(рендер кадров на GPU). Решение записать в журнал.

## 5. Как собрать и выложить

1. Код лежит в `main`. Помощник проверяет: проект ставится (`npm ci`) и собирается без ошибок.
2. Push в `main` (Codex или Claude, через соавтора `tenyls`).
3. Сборка APK: github.com/eai-apps/YAi-Retro-Camera → вверху **Actions** → слева **Build Android APK** →
   справа **Run workflow** → зелёная **Run workflow**. Ждать зелёную галочку (5–15 мин).
4. APK: вверху **Code** → справа **Releases** → последний релиз → файл `.apk`.
5. Установка на Android: открыть ссылку на APK в браузере телефона → скачать → открыть → разрешить «Установку из
   неизвестных источников» → **Установить**.
*(Пункты 3–5 заработают после того, как Codex добавит workflow на Этапе 0.)*

## 6. Правила, которые нельзя ломать

1. **Бюджет НОЛЬ.** Никаких платных серверов, API, облачного ИИ. Всё считается на телефоне. ИИ — только бесплатный
   на самом телефоне (ML Kit / MediaPipe), и не в первой версии.
2. Сервер (если понадобится) — только бесплатный Cloudflare.
3. Заимствовать код / LUT / текстуры / звуки — **только с проверенной лицензией** (MIT, Apache-2.0, CC0…). **GPL не брать.**
   Код Blackmagic Camera закрыт — не использовать. Источник — в `assets/LICENSES.md`.
4. Эффекты **не дешёвые** (не «сепия поверх»): слои = LUT плёнки + живое зерно + засветки + пыль/царапины + виньетка +
   рамка + дата + звук.
5. Каждая камера — отдельный файл в `src/cameras/`; не зашивать камеры в движок.
6. Никаких водяных знаков и лимитов длины записи в бесплатной версии.
7. Ключ подписи и пароли — никогда в git.
